Initial Monte Carlo Setup

This is our v0 Monte Carlo World Cup simulator. Each epoch simulates the full tournament: group stage, ranking, top-two qualification, best third-place qualification, knockout rounds, final, and third-place playoff.

The current model uses official FIFA squads, EAFC-derived player ratings, player positions, and a Poisson goal model. The 10,000-epoch run estimates probabilities rather than deterministic predictions.

Current limitations include simplified knockout routing, no injuries or suspensions, no tactical matchups, no recent-form weighting, and no SofaScore-style performance metrics yet.
